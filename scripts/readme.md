# Scripts

Voorbereidende scripts en notebooks die niet tot de MCP-server horen, maar waarmee de
afgeleide data in de repo wordt gebouwd of gecontroleerd.

De bronbestanden waar deze scripts uit lezen (o.a. de STOWA-rapporten, de per-waterschap
Excels en `stats_data_in.xlsm`) staan in `scratchpad/` — een lokale werkmap die buiten
git blijft (zie het commentaar in `.gitignore`). De afgeleide JSON-bestanden staan wél in
de repo, onder `src/talk_with_the_engineer/tools/toolset_rules_of_thumb/`.
